# Torch resolves to CPU-only wheels by default. Since torch 2.13 the PyPI
# Linux wheels pull cuda-toolkit + nvidia-* packages (~10 GB), which
# overflows the GitHub runner disk ([Errno 28] No space left on device)
# and bloats the image to ~10.8 GB so `exporting to image` crawls.
#
# GPU servers: leave this file as-is and add the CUDA index at build time
# (its +cuXXX wheels outrank +cpu), e.g.
#   TORCH_INDEX_URL=https://download.pytorch.org/whl/cu126 docker compose build api
# or set TORCH_INDEX_URL in .env before `docker compose up -d --build`.
--extra-index-url https://download.pytorch.org/whl/cpu
