============================================================
  P&ID STUDIO WEB PLATFORM
  Otomasi Corrosion System & Circuit pada P&ID (API RP 970)

============================================================


APA INI
-------
Aplikasi web yang membaca gambar P&ID kosongan, mendeteksi
komponennya (pipa, valve, instrumen, equipment, dan line
number), lalu mengelompokkan pipa menjadi corrosion system dan
corrosion circuit dan mewarnainya di atas gambar - berdasarkan
API RP 970.


YANG DIBUTUHKAN
---------------
Pilihan A (Docker - direkomendasikan):
- Docker Desktop (Windows/macOS/Linux)
- Koneksi internet (hanya untuk build/pemasangan pertama)

Pilihan B (Mode lokal tanpa Docker):
- Python 3.11+ (backend FastAPI), Node.js 20+ (frontend Next.js)
- Koneksi internet (untuk memasang dependensi)

Kartu grafis NVIDIA TIDAK wajib. Tanpa GPU aplikasi tetap jalan,
hanya proses deteksi sedikit lebih lama.


CARA MENJALANKAN
----------------
Pilihan A: MODERN WEB PLATFORM (Sangat Direkomendasikan)
  1. Menggunakan Docker (On-Premise Containerized):
     - Pastikan Docker Desktop sudah aktif.
     - Dobel-klik "start_docker.bat" (Windows) atau jalankan
       "./start_docker.sh" (Linux/macOS).
     - Buka browser di http://localhost:3000.
     - Backend API & Dokumentasi Swagger otomatis tersedia di
       http://localhost:8000/docs.

  2. Menggunakan Mode Lokal (Tanpa Docker):
     - Dobel-klik "start_local.bat" (Windows).
     - Backend FastAPI (Port 8000) dan Next.js Web UI (Port 3000)
       akan berjalan di terminal terpisah.


CARA MEMAKAI (SINGKAT)
----------------------
  1. Buat project / buka salah satu sheet di folder "Contoh P&ID".
     Disarankan mulai dari:
        BCD3-605-42-PID-1-001-01 REV.6J0-CCD2.png

  2. Klik  "Detect P&ID".  Sistem akan mendeteksi semua komponen
     dan membaca line number-nya. Progres deteksi tampil sebagai
     loading/progress bar di kanvas (tetap terlihat walau pindah
     tab dan kembali).

  3. Buka mode tampilan untuk berpindah antara Digitization,
     Corrosion System, Corrosion Circuit, Multi-Sheet Topology,
     dan Validation & Report.

  4. Panel kanan menampilkan daftar pipa, sistem korosi, circuit,
     simbol, dan OPC. Gunakan alat kanvas (Box Trace, Manual Pen,
     Split) untuk mengoreksi hasil deteksi.


ISI FOLDER
----------
  frontend/ ................ Web UI (Next.js / React / Tailwind)
  backend/ ................. REST API (FastAPI) + Celery worker
  pidcorr/ ................. modul CV & engine (deteksi, tracing,
                             pengelompokan API RP 970)
  runs/ .................... model AI yang sudah dilatih
  Contoh P&ID/ ............. gambar P&ID untuk dicoba
  combined_dataset/ ........ data acuan engineer (untuk Validation
                             & Report)
  data/ .................... data uji equipment + storage runtime
  scripts/ ................. smoke test & tooling
  docs/ .................... dokumentasi arsitektur & deployment
  .pidcache/ ............... cache hasil deteksi (runtime)
  docker-compose.yml ....... orkestrasi seluruh stack
  start_docker.bat / .sh ... launcher Docker (Windows / Linux-macOS)
  start_local.bat .......... launcher mode lokal tanpa Docker


KALAU ADA MASALAH
-----------------
Cek status container dengan  "docker compose ps"  dan lihat log
dengan  "docker compose logs -f api worker frontend".
